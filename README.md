# DocuHWPX Studio - 로컬 메모리 전용 HWPX 변환기

한컴오피스 **HWPX(한글 XML 표준 문서)** 파일을 웹 브라우저 메모리 안에서만 직접 읽고, **마크다운(Markdown, `.md`)** 및 **고품질 PDF(`.pdf`)**로 변환해 주는 순수 클라이언트 사이드 웹 애플리케이션입니다.

---

## 🔒 100% 보안 및 프라이버시 원칙
- **외부 서버 전송 Zero**: 업로드한 문서는 어떠한 외부 서버나 클라우드로 전송되지 않습니다.
- **로컬 메모리(RAM) 처리**: 브라우저의 `ArrayBuffer` 및 `DOMParser`를 이용해 사용자 컴퓨터 메모리에서만 파싱 및 변환됩니다.
- **오프라인 동작**: 인터넷 연결이 차단된 폐쇄망이나 오프라인 환경에서도 완벽하게 작동합니다.
- **별도 프로그램 설치 불필요**: Python, Node.js, 웹 서버 구동 없이 `index.html` 파일을 더블 클릭하여 바로 사용할 수 있습니다.

---

## 🚀 사용 방법
1. 탐색기에서 **[`index.html`](file:///c:/Users/AK/Desktop/docu_analyzer/index.html)** 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Whale, Firefox 등)로 엽니다.
2. 변환하고자 하는 **`.hwpx` 파일**을 드래그 앤 드롭하거나 **[파일 찾아보기]** 버튼으로 선택합니다.
3. 변환이 완료되면 즉시 다음 기능을 이용할 수 있습니다:
   - **📄 문서 양식 뷰**: 실제 A4 문서 규격으로 깔끔하게 렌더링된 결과를 확인합니다.
   - **📝 마크다운 소스 편집기**: 변환된 마크다운을 직접 수정하거나 복사할 수 있습니다.
   - **📥 마크다운 (.md) 저장**: 원본 파일명과 일치하는 `.md` 파일로 다운로드합니다.
   - **📋 마크다운 복사**: 원클릭으로 클립보드에 복사합니다.
   - **🖨️ PDF 인쇄 / 저장 (권장)**: 브라우저 기본 인쇄 다이얼로그를 통해 글자 깨짐 없는 초고화질 벡터 PDF로 저장합니다.
   - **⚡ PDF 직접 다운로드**: 1클릭으로 즉시 `.pdf` 파일을 다운로드합니다.

> 💡 **샘플 체험 기능**:
> 컴퓨터에 당장 HWPX 파일이 없더라도 화면의 **[✨ 샘플 문서 즉시 체험하기]** 버튼을 누르면 인메모리 샘플 HWPX가 생성되어 1초 만에 동작을 테스트할 수 있습니다.

## 🛠️ 기술 구성 (순수 바닐라 스택)
- **`index.html`**: 애플리케이션 구조 및 UI
- **`style.css`**: 다크/라이트 테마, A4 인쇄 규격 스타일링(`@media print`), 글래스모피즘
- **`hwpx-parser.js`**: KS X 6101 HWPX ZIP 컨테이너 XML 파서 (문단, 제목, 서식, 표, 이미지 추출)
- **`sample-generator.js`**: 인메모리 샘플 HWPX 아카이브 실시간 생성기
- **`app.js`**: UI 이벤트 제어, 실시간 렌더링 동기화, 파일 내보내기 로직
- **`jszip.min.js`**: 클라이언트 사이드 ZIP 압축 해제 라이브러리 (로컬 오프라인 탑재)
- **`marked.min.js`**: 실시간 마크다운 렌더러 (로컬 오프라인 탑재)
- **`html2pdf.bundle.min.js`**: 클라이언트 PDF 직접 생성 라이브러리 (로컬 오프라인 탑재)
